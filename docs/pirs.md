# PIRS

PIRS consumes compiled design matrices and produces model, residual, HSIC, ranking, dashboard-card, and report artifacts. Standard and deep HSIC require cross-fitted residuals.

HSIC supports exact, Nyström, and random Fourier feature kernels. Empirical null manifests record requested/executed permutations, null regime, block counts, seed, device, approximation diagnostics, and FDR family. Invalid, constant, non-finite, or under-blocked support is descriptive-only or blocked explicitly.
